# AHI standard methods

The public stages cover prepared-array extraction, optional projection,
same-time mosaic, both study-area routes and split-window LST using AHI bands
14 and 15. GeoTIFF is the new prepared/data/result format; legacy prepared
NPZ files remain readable. Native Himawari NetCDF decoding and ten-minute/year
traversal remain in `cases/ahi/` until paths, product version and quality masks
are validated.
