supervisor: Zunjian Bian, Qing Xiao
recommend python version: 3.11
=================
what can do:
1. retrieve dual-angle LST
2. retrieve two/three component LSCT
================
how to use:
1. download the slstr L1B product / ERA5 tcwv data / LAI data
2. unzip with slstr_unzip.py
3. extract and reproject data to taget area with slstr_data.py
4. process ERA5 tcwv data with era5_tcw_data.py
5. retrieve LST with slstr_lst.py
6. retrieve LSCT with slstr_lsct2.py or slstr_lsct3.py
