# AHI legacy draft case

这些脚本从 `old/` 迁入，当前登记状态为 `draft`。目录按 `data/`、`lst/`、`auxiliary/`、
`angular/`、`temporal/` 和 `uncertainty/` 分类。与 SLSTR 联合处理的脚本不归属于任一
单传感器，位于
`cases/_archive/shared/legacy_cross_sensor/cross_sensor/slstr_ahi/`。

在标记 active 前，需要确认绝对路径、输入产品版本、研究区、空间处理方式和可复现的
最小运行步骤。

现有内容混有中国目标网格、黑河站点及多台 Windows 机器路径，所以暂用
`unclassified`，不能把它描述成单一黑河正式案例。
