AATSR
================

version: 1.0
reformate date: 2026-1-4
author: TIRTLab (Yifan Lu, luyifan22@mails.ucas.ac.cn)
supervisor: Zunjian Bian, Qing Xiao
recommend python version: 3.11
=================
what can do:
1. retrieve dual-angle LST
2. retrieve two/three component LSCT
================
how to use:
1. download the aatsr L1B product(N1 formate) / ERA5 tcwv data / LAI data
2. unzip with aatsr_unzip.py
3. extract data with aatsr_data.py
4. process ERA5 tcwv data with era5_tcw_data.py
5. retrieve LST with aatsr_lst.py
6. retrieve LSCT with slstr_lsct.py
7. generate month average result with aatsr_month_avg.py
