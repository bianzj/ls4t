# AATSR 组分温度反演：方法与现有实现

核对日期：2026-10-15。本文整理现有源码中的方法，不代表各历史脚本已完成真实 AATSR 数据运行验证。

方法应按四个独立维度描述：**植被结构权重 × 空间温度假设 × 组分温差约束 × 空间与角度信息融合**。NDVI、LAI、SLSQP、贝叶斯分别处于不同层次，可以组合，不能直接当作互斥的四种算法。

## 1. NDVI 与 LAI 如何参与植被结构计算

两组分的基本观测模型为：

\[
b_{p,a}=w_{s,p,a}B_\lambda(T_{s,p})+w_{v,p,a}B_\lambda(T_{v,p})+\epsilon_{p,a}.
\]

其中，`p` 为像元，`a` 为观测角度；`b` 是按相应辐射模型转换后的观测；`w` 是组分有效发射率权重。NDVI/LAI 主要决定 `w`，温度反演求解的是各组分辐射量，再通过逆 Planck 函数转换为温度。

| 结构方案 | 计算方式 | 角度信息如何进入 | 当前代码 |
| --- | --- | --- | --- |
| NDVI → 方向植被覆盖度 | `fvc = clip((NDVI-NDVI_min)/(NDVI_max-NDVI_min), 0, 1)`；简单权重为 `[emisS*(1-fvc), emisV*fvc]` | 分别使用正视、前视 NDVI 得到两套权重 | [aatsr_lsct_ndvi.py](../cases/aatsr/aatsr_lsct_ndvi.py)，主程序 |
| LAI → 冠层孔隙率 | `fvc(theta) = 1-exp(-0.5*LAI/cos(theta))`；再计算简单混合权重 | 同一 LAI 配合不同观测天顶角 | [aatsr_lsct.py](../cases/aatsr/aatsr_lsct.py)，`cal_fvc_from_lai`；站点贝叶斯当前主分支也采用此方式 |
| LAI → 冠层辐射传输权重 | 使用均匀冠层模型、热点参数、太阳/观测几何与有效发射率计算 | 显式使用观测天顶角、太阳天顶角和相对方位角 | [base/lsct.py](../base/lsct.py)，`cal_effective_emissivity_hom`；v3.1 和站点 LAI 分支 |

这里的“植被结构”主要指冠层遮挡、可见组分比例及其辐射权重。NDVI 覆盖度或单个 LAI 值都不能独立确定完整三维结构；简单 NDVI 两组分权重也不能直接拆出阳照土壤、阴影土壤和植被三组分。

LAI 孔隙率模型与完整冠层有效发射率模型应分别列为 `LAI-gap` 和 `LAI-RT`，避免把权重模型的变化归因于 LAI 本身。

## 2. “是否考虑温度差异”需要分开回答

| 温度差异的含义 | 现有处理 | 解释 |
| --- | --- | --- |
| 同一像元中土壤与植被不同温 | 两组分方法均分别求 `Ts` 和 `Tv` | “窗口同温”仍允许 `Ts != Tv` |
| 邻近像元之间，同一组分的温度不同 | 窗口常量模型不允许；空间二次曲面模型允许 | 常量模型假设窗口内所有土壤共享一个温度、所有植被共享另一个温度 |
| 限制组分间温差的大小/符号 | SLSQP 分支施加显式约束；普通 LS、Ridge 和现有 MAP 分支没有同样的温差约束 | 温差约束与空间异温是独立选择 |

空间二次曲面是在**辐射量**上建模：每个组分使用 `1, x, y, xy, x², y²` 六个系数，而不是直接令温度为二次曲面。两组分共有 12 个系数，利用窗口内双角度观测拟合后得到中心组分辐射量。

角度差异在这些模型中主要改变组分可见比例。中心像元的同一组分温度在两次观测方程中共享；这不等于显式求解“同一组分随角度变化的本征温度”。

### SLSQP 温差约束的实际含义

- 两组分白天：名义 `Ts-Tv` 范围为 `[-5, 30] K`。
- 三组分白天：名义阳照土壤减阴影土壤为 `[5, 40] K`；阴影土壤减植被为 `[-15, 15] K`。
- 站点两组分夜间分支不施加上述温差约束，另设单组分取值边界。

代码用中心观测平均温度 `Tbar` 将温差端点 `d` 转为辐射差端点：

\[
\Delta B(d)=B_\lambda(\bar T+d/2)-B_\lambda(\bar T-d/2).
\]

然后约束待求组分的辐射差。它是围绕 `Tbar` 构造的温差近似约束，**不严格等价于直接约束最终反演的 `Ts-Tv`**。现有函数第二个 Planck 项写死波长 10.8；默认 `wl=10.8` 时与上式一致，改变波长时需修正。代码还包含组分取值边界及组分辐射范围包围中心观测辐射的约束。

SLSQP 是求解这些约束优化问题的数值方法。约束定义见 [base/lsct.py](../base/lsct.py) 的 `constraint_func_Nangle_2component` / `constraint_func_Nangle_3component`；窗口求解见 [base/lsct_window.py](../base/lsct_window.py) 的 `fitting_Nangle_Mcomponent_window`。

## 3. 贝叶斯怎样分步利用空间与角度信息

现有代码采用“邻域先验 + 中心双角度更新”的线性高斯融合形式。令 `r` 为中心组分辐射向量，邻域估计给出先验均值 `mu` 和指定先验协方差 `Cm`，中心观测为 `b0 = W0*r + error`、误差协方差为 `Cd`：

\[
\hat r=(W_0^T C_d^{-1}W_0+C_m^{-1})^{-1}
       (W_0^T C_d^{-1}b_0+C_m^{-1}\mu).
\]

| 实现 | 空间先验来源 | 中心更新 | 是否显式限制组分温差 |
| --- | --- | --- | --- |
| v3.1 的 v3 | 5×5 窗口常量模型的 LS 解，即 v2 | 中心像元双角度观测 | 否 |
| 站点贝叶斯 `line_inv_2_s` | 5×5 空间二次曲面；一般对有效位置的曲面预测做空间加权平均，特殊情况下取中心预测 | 中心像元双角度观测 | 否；存在辐射取值筛选 |

两者默认 `Cm=diag(2,1)`、`Cd=0.05*I`。这些数值在公式中充当**辐射空间方差**，不能直接解释为 2 K、1 K 或 0.05 K 的温度误差。

这实现了空间信息与中心角度信息的**分步使用**。但邻域先验已使用双角度数据，而且包含中心像元；因此不能宣称空间与角度信息统计独立，也不能把结果解释成两个独立信号的分解。同一中心观测可能被重复利用，相关性尚未在上述简单公式中显式处理。

若要建立更严格的对照，应从先验拟合中排除中心观测，并评估剩余空间相关性；或建立统一的联合概率模型，显式描述共享观测与协方差。两种方式均属于后续设计，当前源码未完整实现。

普通 Ridge，或单独调用 `BayesianRidge` 回归器，不等于上述“邻域先验 + 中心角度更新”。

## 4. 现有方法对照与代码入口

“空间异温”专指窗口内同一组分可随像元变化；所有两组分方法都允许土壤与植被不同温。

| 方法 | 结构权重 | 空间异温 | 显式组分温差约束 | 空间先验与中心角度分步融合 | 代码入口 |
| --- | --- | --- | --- | --- | --- |
| 正式两组分 Ridge | LAI-gap | 否，5×5 常量 | 否 | 否，窗口双角度一起拟合 | [aatsr_lsct.py](../cases/aatsr/aatsr_lsct.py)：主程序、`fitting_with_ridge` |
| NDVI 两组分 SLSQP | NDVI | 否，5×5 常量 | 有 | 否，窗口双角度一起拟合 | [aatsr_lsct_ndvi.py](../cases/aatsr/aatsr_lsct_ndvi.py)：`aatsr_inv_lsct2_window` / `aatsr_inv_lsct2_Line` |
| 站点两/三组分 SLSQP | LAI-RT；两组分另有 NDVI 分支 | 否，窗口常量 | 白天有 | 否 | [aatsr_site_inv.py](../cases/aatsr/aatsr_site_inv.py)：`inv_lsct2_window` / `inv_lsct3_window` |
| v3.1 v0 | 主程序采用 LAI-RT | 有，辐射二次曲面 | 否 | 否 | [aatsr_lsct_v31.py](../cases/aatsr/aatsr_lsct_v31.py)：`inv_lsct2_v3_1` 的 `p0` |

## 5. 方法存在与实现可用需要区分

以下结论来自当前源码核对；本次只整理文档，没有改动求解器。

1. **空间二次曲面分支有运行阻塞。** `base/lsct.py` 的 `fitting_Nangle_Mcomponent_window_quadratic` 和站点贝叶斯脚本使用 `scipy.linalg.lstsq(..., rcond=None)`；当前 Python311 环境实测该函数不接受 `rcond`。前者捕获异常后返回 NaN，后者可能直接报错。故表中记录的是已写出的建模思路，不能据此宣称该分支已经可运行。
2. **三组分贝叶斯尚未完整实现。** 站点 `line_inv_3_s` 仍保留两元素先验及 2×2 先验协方差等两组分逻辑，与三组分维度不一致。
3. **NDVI + 三组分不是现成组合。** 站点 NDVI 分支只构造两个组分权重；三组分需额外的阳照/阴影分解模型。站点贝叶斯主程序中的 NDVI 权重代码目前被注释，不能仅修改 `if_ndvi` 就认定切换成功。
4. **名称不能替代调用核对。** 正式 Ridge 产品元数据中的 `bayesian` 字样与实际求解不符；v3.1 的 `wincons` 表示窗口常量，不能理解为温差约束，其 `ifcons` 参数也没有实际控制约束。
5. **SLSQP 结果需要补充收敛检查。** 当前 `fitting_unknown_nonlinear_min` 返回 `res.x`，没有检查优化成功状态或最终约束残差；“传入约束”不代表每个输出都成功满足约束。
6. **结构联合优化不属于当前主流程。** 站点脚本虽定义 `optimize_LAI`，主程序调用被注释，不能称为已实现 NDVI、LAI 与组分温度的联合反演。

## 6. 用于后续比较的统一方法体系

建议用明确的配置维度命名方法，而不是延续含义不明确的版本号：

```text
structure  = ndvi | lai_gap | lai_rt
spatial    = pixel | constant | quadratic
constraint = none | component_delta_t
fusion     = joint | spatial_prior_map
components = 2 | 3
```

这是整理实验的配置约定，尚未作为统一运行接口实现；不是所有组合都已有可用代码。

最小对照分四组开展，每次固定其余条件：

| 要回答的问题 | 对照设计 |
| --- | --- |
| NDVI 与 LAI 的结构信息有何影响？ | 两组分、相同常量窗口和求解器下比较 NDVI 与 LAI-gap；LAI-RT 另列结构模型实验 |
| 组分温差先验有何影响？ | 相同结构和空间模型下比较无约束与温差约束 |
| 空间温度变化有何影响？ | 相同权重及无温差约束下比较窗口常量与空间二次曲面 |
| 分步贝叶斯融合有何影响？ | 相同结构及先验空间模型下比较窗口拟合结果与中心角度更新结果；单独报告协方差设定和中心观测重复使用问题 |

统一观测日期/区域、配准网格、质量掩膜、发射率、波长、辐射转换、窗口大小和验证样本。现有脚本在 NDVI 端点、散射处理、筛选阈值等方面不同，不能把历史结果的差异全部归因于 NDVI/LAI 或贝叶斯。

每组至少报告有效反演率、观测重建残差、数值稳定性、温差约束满足率；有匹配组分实测时再报告组分温度误差。观测重建残差小不等于组分温度准确，三组分也不能仅靠单像元两个角度唯一确定。
